# 花笺 Workbench

一个放在电脑上的温柔工作角落。把日历、待办、专注、便笺和桌面贴图放在一起，适合个人安排和日常行政办公。

**Windows 10 / 11，64 位。数据保存在本机。**

## 下载与运行

到 [Releases](https://github.com/AureliusWu/Workbench/releases) 下载 `Workbench-版本号-win-x64.exe`，双击运行，无需安装 Node.js 或浏览器。便携程序启动时需要解压运行环境，本机验证约需 9 秒，请耐心等待片刻。

发行版尚未购买代码签名证书，Windows 可能显示发布者未验证。请只从本仓库发行页下载，并用发行页中的 SHA-256 校验值确认文件来源。

## 能做什么

- **今天与日历**：日历与有日期的待办共用同一份数据，显示农历、节日与节气倒计时。
- **待办与小步骤**：设置优先级、日期、时间、提醒和重复规则；大事拆成可逐项打勾的小步骤，完成后划线。
- **安排大任务**：给出预计总时长与每天可投入时间，按工作日拆分安排。
- **番茄钟**：开始、暂停、重置专注与休息，完成专注后累计记录。
- **随手记**：记录临时想法，也可把便笺单独置顶在屏幕上。
- **周复盘**：查看真实完成率与专注记录，保存个人复盘；可选连接自己的 AI 服务获取建议。
- **截图与贴图**：框选截图后直接置顶，也可把剪贴板中的图片钉在屏幕上作为参考。
- **文件聚合**：选择一个本地文件夹，按类别浏览并打开文件。
- **本地备份**：导出、导入 JSON 数据备份，便于主动保存和换电脑迁移。

本版以 Windows 本地使用为范围。参考资料中的手机账号同步、新闻订阅、OCR、长截图、录屏属于其他产品能力，不包含在本版承诺中。

## 月末周六规则

默认启用“每个月最后一个周六上班”。判断优先考虑中国大陆官方放假安排：**遇官方假期仍休息**，不会因为月末周六被改为上班；其余日期结合官方调休与普通双休日判断。

日历提供手动调整日期状态的入口。官方假期数据有明确适用年份，超出已收录年份会显示提示，不能视为已经获得当年的官方调休安排。详细来源和规则见应用中的日历说明及 [日历数据来源](docs/CALENDAR-SOURCES.md)。

## 提醒、问安与后台运行

提醒和每日问安需要 Workbench 进程运行。关闭主窗口后保留托盘，使用托盘菜单可重新打开或彻底退出；彻底退出、电脑关机时不会弹出提醒。Windows 的通知设置、专注助手也可能影响通知显示。

可以在设置中开启登录后启动。请按自己的使用习惯选择，默认不强制开启。

## AI 复盘

无需 AI 也可查看统计、使用本地建议并保存复盘。需要外部 AI 建议时，在设置中填写兼容接口地址、模型和自己的 API Key。

只有主动点击生成 AI 复盘时，才会将该次复盘所需内容发送给所配置的服务；服务可能收费，请使用自己的账户。API Key 由 Windows 本机加密保存，不写入导出备份，也不跟随 GitHub 源码上传。AI 建议仅供参考，请自行核对。

## 数据与迁移

数据保存在 Windows 当前用户的 `%APPDATA%\Workbench\workbench.json`，运行文件所在位置与数据位置分离。移动或更新 EXE 不会主动清除记录。

建议定期在设置中“导出备份”，将 JSON 保存到你选择的位置；换电脑后运行 Workbench 并“导入备份”。导入会替换工作台当前数据，请先导出已有内容。API Key 需要在新电脑重新填写。

源码、发行文件与个人记录分别保存；仓库不会包含你的任务、便笺、截图或密钥。

## 开发

需要 Node.js 22.12+，推荐 Node.js 24 LTS，以及 Windows 10/11 x64。

```powershell
npm ci
npm run build
npm start
```

前端热更新：

```powershell
npm run dev
# 另开一个 PowerShell
$env:WORKBENCH_DEV_URL = 'http://127.0.0.1:5173'
npm start
```

测试与打包：

```powershell
npm test
node --test scripts/native-test.cjs
npm run build
npm run test:e2e
npm run dist
```

`release/` 包含便携 EXE。端到端测试使用独立临时数据目录，不修改日常记录。运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/generate-icon.ps1` 可重新生成图标。
