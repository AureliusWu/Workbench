# 发行验证记录

本文件描述可重复执行的发行检查方法。具体结果由发行时的日志、GitHub Actions 和发行说明记录，不能把本清单当作已通过的证据。

## 构建与验证

```powershell
npm ci
npm run build
npm test
node --test scripts/native-test.cjs
npm run test:e2e
npm run dist
```

- TypeScript 与 Vite 生产构建通过。
- 日期、节假日、月末周六、重复事项、自动拆分、周统计单元测试通过。
- Electron 实际窗口可启动，核心待办、完成划线、便笺、设置和重启保留数据可用。
- 原生窗口、托盘、截图与贴图另外观察，不能用浏览器截图代替原生功能验证。
- 在独立数据目录运行打包后的 EXE，记录版本、启动耗时与窗口结果。
- 计算发行 EXE 的 SHA-256，上传同一文件和校验清单。
- 发布后读取真实 Release 的资产列表和下载地址，确认标签对应的提交。

## 数据审查

- 初始任务与统计为空；个人记录不写入源码。
- 官方日历适用年份可见，未知年份不假装已核实。
- 不将缺失数据强制转成一条成功记录。
- 备份导入验证结构；损坏文件不直接覆盖现有数据。
- API Key 不出现在 load 返回值、JSON 导出或日志里。
- 默认 AI 请求不发生；用户主动生成时才请求配置的服务。

## 性能预算

首版没有上一发行版基线，记录当前版本作为后续比较点。生产页面渲染与一次待办交互各采样三次，记录中位数与最慢样本。页面核心工作流程预算 3 秒；便携 EXE 的首次自解压单独记录，不与已解压程序启动混算。

## 回退

更新前导出 JSON。关闭托盘中的 Workbench，保留本版 EXE 和备份，再运行上一版本。若未来版本修改数据格式，应先检查其迁移说明；不要盲目把新格式文件覆盖旧版本。

## 本版公开限制

- 未购买代码签名证书。
- 提醒需要进程运行，关机或彻底退出后不提醒。
- AI 实际服务连通、计费与建议质量取决于用户配置的提供方。
- 官方假期适用范围以应用中收录年份为准。
- 不含手机云同步、OCR、长截图与录屏。
