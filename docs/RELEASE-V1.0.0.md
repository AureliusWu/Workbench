# 花笺 Workbench 1.0.0

Windows 10 / 11 x64 本地个人与办公工作台。下载 **Workbench-1.0.0-win-x64.exe** 后双击运行，无需安装 Node.js、浏览器或额外运行库。

便携程序每次启动需要解压运行环境，本机实测约 9 秒；这是单文件封装的等待时间。

## 本次功能

- 粉白、淡紫配色的中文工作台，日历、今日计划、专注和灵感放在一起。
- 待办优先级、提醒、完成划线、可勾选小步骤、每日／每周重复与系列编辑。
- 按总时长和每天上限，将大任务自动分配到工作日。
- 每月最后一个周六默认上班；官方放假优先休息。内置核实过的中国大陆 2026、2027 年放假调休表，超出年份明确提示待更新。
- 番茄钟、节假日与节气倒计时、晨间问安、周完成率与复盘笔记。
- 随手记、桌面置顶便笺、框选截图直接贴图、剪贴板图片贴图，支持缩放与透明度。
- 按类型浏览本地工作文件夹；导出、恢复 JSON 数据备份。
- 可选连接兼容 Chat Completions 的 AI 服务生成周复盘建议，密钥使用 Windows 本机加密保存。

## 快捷键

- `Ctrl + N`：新建待办。
- `Ctrl + Alt + A`：框选截图并贴到桌面。
- `Ctrl + Alt + V`：将剪贴板图片贴到桌面。
- `Esc`：关闭贴图或取消截图。

## 使用说明

数据保存在 `%APPDATA%\Workbench`。关闭主窗口后继续驻留托盘，使用托盘菜单可彻底退出。提醒和问安需要程序运行；Windows 的通知设置会影响系统通知。

AI 为可选功能，需要配置自己的服务与模型；只有主动生成时才发送本周内容。发行验证使用本机模拟服务，没有调用付费模型。未配置 AI 也可使用本地建议和全部基础功能。

发行文件未购买代码签名证书，Windows 可能显示“发布者未验证”。请从本仓库发行页下载，并按随附 `SHA256SUMS.txt` 核对文件。更新前可在设置中导出备份；保留旧 EXE 即可回退，导入备份可恢复数据。
