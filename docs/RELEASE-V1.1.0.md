# 花笺 Workbench 1.1.0

下载 `Workbench-Setup-1.1.0-win-x64.exe` 并双击，一键安装到当前 Windows 用户。安装完成后会打开新版工作台，可从开始菜单或桌面再次打开。

## 安装与升级

1. 如果 1.0.1 便携版仍在运行，先从系统托盘退出「花笺 Workbench」。
2. 双击安装包。已安装的 Workbench 会沿用安装路径更新程序文件。
3. 新版继续读取 `%APPDATA%\Workbench`。待办、复盘、便笺、设置和本机密钥都沿用原有数据。第一次保存新版数据前，会把旧主文件原样保存到 `backups\before-1.1.0.json`，可用于恢复。

1.0.1 以独立便携 EXE 发行。转入安装版后使用新快捷方式，原便携文件仍在原来的位置。1.1.0 新增了无日期待办和便笺字段，升级后请使用新版继续编辑。安装包未做代码签名，Windows 可能弹出发布者提示。附件 `SHA256SUMS.txt` 可用于校验下载。

## 更新内容

- 首页显示周一到周日的日程和本周待办。点击日历标题可编辑，任务完成后在日历与列表都显示删除线。
- 输入「明天下午三点开会」并回车，得到明天 15:00 的「开会」待办。模糊时段可留空，支持先记下没有日期的事项。
- 按日期或历史周查看复盘，导出所选周的 Markdown，包含待办、统计与复盘正文。
- 用多个标签整理便笺。归档后可在归档区找回，恢复时保留正文和标签。
- 导入旧格式备份时补齐新字段。确认导入后会先保存当前数据的独立恢复副本。

原有月历与月末周六规则、任务提醒、专注计时、文件速达、截图贴图和可选 AI 复盘仍可使用。AI 复盘仍使用你配置的服务。
