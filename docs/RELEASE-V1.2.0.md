# 花笺 Workbench 1.2.0

下载 `Workbench-Setup-1.2.0-win-x64.exe`。先从托盘退出旧版，再双击安装包。安装器沿用原安装路径，并继续读取 `%APPDATA%\Workbench` 中的记录。

## 界面与操作

- 浅色圆角工作台，淡紫日历和便笺卡片，今日日期突出显示。
- 在周日历直接勾选完成。`Ctrl + K` 搜索待办、子步骤和便笺。
- 文件夹可用键盘进入和返回。打开另一条便笺前会提示保存或放弃当前草稿。
- 修复日期解析误判，重排小步骤时保留历史勾选。修改重复日期或频率时保留过去日程。

## 自动更新

安装 1.2.0 后，从右上角「应用更新」查看版本和下载进度。安装版默认在后台检查并准备新版，签名和 SHA-256 校验通过后可点「重启更新」。可关闭自动检查，之后仍可手动检查。

1.1.0 及更早版本需手动安装这一次。跟随发行的 `workbench-update.json` 是供应用验证的签名清单。手动安装可通过 `SHA256SUMS.txt` 验证文件，Windows 可能提示安装包发布者未验证。

更新沿用现有数据目录和格式。待办、复盘、便笺与本地加密密钥随 Windows 用户保留。
