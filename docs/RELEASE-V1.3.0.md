# 花笺 Workbench 1.3.0

## 两日清单

- 从左侧「两日清单」打开今天和明天。输入标题并按 Enter，就能把待办记到所在日期。每列显示当地日期、工作日状态、待完成事项和完成进度。
- 未完成的单次待办可用双箭头在两天之间改期。「待安排」收录逾期和未排期的单次待办，可主动排到今天。当前日期切换时，过去任务的日期及完成记录继续保留。
- 新建待办时可选准备会议、整理报销或家庭采买模板。模板补充可勾选步骤，保留已填名称和自定用时。

## 安装与更新

- 已安装 1.2.0 时，可从右上角「应用更新」检查，下载校验完成后选择「重启更新」。
- 1.1.0 及更早版本可先从托盘退出旧版，再双击 `Workbench-Setup-1.3.0-win-x64.exe`。安装器沿用旧路径，本机数据仍从 `%APPDATA%\Workbench` 读取。
- 待办、历史复盘、便笺以及 Windows 加密的 API Key 会保留。任务数据和 JSON 备份继续使用 schema 1。

应用使用内置 Ed25519 公钥和 SHA-256 校验更新。Windows 安装器未做 Authenticode 签名，可能显示发布者提示。
